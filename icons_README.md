# Dragonfly App Icons

You need two PNG files in this folder:
  icon-192.png  (192x192 pixels)
  icon-512.png  (512x512 pixels)

## Quickest option — generate from the SVG below

1. Copy the SVG code below into a file called icon.svg
2. Go to https://cloudconvert.com/svg-to-png
3. Upload icon.svg, set output size to 512x512, convert
4. Save as icon-512.png
5. Repeat at 192x192 for icon-192.png
6. Put both files in this /icons/ folder on GitHub

## SVG Source (Dragonfly icon — gold dragon on dark green)

  <!-- Border -->
  <rect x="8" y="8" width="496" height="496" rx="74" fill="none" stroke="#d4af37" stroke-width="8"/>
  <!-- D letter mark -->

        font-family="Georgia, serif" 
        font-size="320" 
        font-weight="bold"
        fill="#d4af37" 
        text-anchor="middle">D</text>
  <!-- Dragonfly wordmark -->
  <text x="256" y="440" 
        font-family="Arial, sans-serif" 
        font-size="52" 
        font-weight="bold"
        fill="rgba(212,175,55,0.6)"

</svg>

## Alternative — use any image editor
Create a 512x512 PNG with:
  Background: #05140b (dark green)
  Your logo or the letter D in #d4af37 (gold)
